# 开工清单

- [ ] 原视频 ≥ 1080p（最好 4K），≤ 5 分钟，确认有使用权
- [ ] 记下有效画面区域、字幕 / 台标遮挡区
- [ ] 切点：scdet 自动 + 人工复核
- [ ] 音乐：分轨、节拍、重音表、母带（−12 LUFS）
- [ ] 2D：多人姿态 + 跟踪；每个镜头段选主角；身份修正表
- [ ] 全身 2D（133 点，4K）；身份改过的帧补跑
- [ ] 3D：GVHMR 分段 → 对齐舞台坐标 → 逐帧全身拟合 → 锁脚
- [ ] 验收：重投影、停点帧差、峰速（见 docs/08）
- [ ] 动作母带：合并、补缺口（标记推断）、修抽动帧
- [ ] 导演意见里的局部修动作 → 新文件，原母带不动
- [ ] 镜头表：每镜头 4–15 秒、一个连续机位、重音落点、招牌动作的设计角度
- [ ] 竖屏：安全区自动拟合，首尾余量 0.4 秒
- [ ] Clay：中灰穿衣人偶、灰地面 + 网格
- [ ] 原片参考：同一秒；挡脸框用修正后的身份
- [ ] 提示词：编辑模式模板 + 一致性句 + 片段秒数
- [ ] 480p 试 3–5 个镜头定外观
- [ ] 高清整片：≤ 3 并行，先发一条验证分辨率
- [ ] 每条出片看缩略图条：黑场 / 服装 / 多余人物 → 重做
- [ ] 对拍：测量映射 + 关键动作人工抽查
- [ ] 白平衡统一、超分、调色、克制的特效、文字
- [ ] 冷开场、安全区、水印、结尾淡出
- [ ] 响度 −12 LUFS、真峰值 ≤ −1 dBTP（换编码器后复测）
- [ ] 授权确认（docs/11）
