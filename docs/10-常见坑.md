# 常见坑与对策

| 坑 | 症状 | 对策 |
|---|---|---|
| 参考模式生成 | 动作「完全不一样」、不卡拍 | 只用编辑模式；提示词开头写「编辑 @视频1……逐帧继承」 |
| 身份跟错人 | 一段动作其实是伴舞的 | 服装线索对着原片确认；人工身份修正表 |
| 整体平滑 | 顿点、爆发被抹平，动作软 | 不做全局平滑；重音处放松先验 |
| 太空步锁脚 | 滑步被锁死 | 只在 2D、3D 都静止时锁 |
| 只改动作参数 | 渲染结果没变 | 同步更新母带里存的顶点和关节 |
| 泥塑左右镜像 | 生成的动作左右反 | 渲染器手性用原片核对一次 |
| 参考文件同名 | 多个镜头用了同一份参考 | 上传文件名用内容哈希 |
| 白色裸体人偶 | 提交被输入审核拒 | 人偶中灰 + 穿衣 |
| 露脸原片参考 | 以版权拒绝 | 模糊脸 → 帽檐阴影；挡脸框用修正后的身份 |
| 模糊框落在别人脸上 | 以「可能包含真人」拒绝 | 同上 |
| 提示词写「光束在第 X 秒一亮」 | 模型把之前全部做成黑场 | 加一致性句：光从第一帧到最后一帧一直亮着 |
| 服装在背面 / 顶光下变灰、变米色 | 一致性差 | 一致性句：黑西装在任何角度都是纯黑；重做 |
| 高机位 | 模型把镜头拉回平视拍天际线 | 写清「从高处看到的是什么」 |
| 横版偏置构图用到竖版 | 人出画 | 竖屏 `lat = 0`，安全区自动拟合 |
| 拉伸生成镜头补长度 | 动作慢慢脱拍 | 首尾留 0.4 秒余量，测量后逐帧映射 |
| 速度信号短窗互相关 | 偏移方向判反 | 用姿态 DTW / 姿态窗口；关键动作人工核对 |
| 冷暖色在镜头间跳 | 看起来像不同片子 | 亮部白平衡向定调镜头校正 70% |
| 真人画面上叠重 CG 特效 | 显得廉价 | 克制：余烬、微光、曝光冲击 |
| 自带 AAC 编码 | 某个瞬态冲到 +2.5 dBFS | 用 `aac_mf` 或过采样限幅后复测 |
| 歌词上屏 | 版权风险 | 只用片名和自己写的字 |
