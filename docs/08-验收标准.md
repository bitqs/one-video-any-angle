# 验收标准

每一步过关再往下走。数字来自范例实测，可作为默认门槛。

| 步 | 指标 | 门槛 | 怎么查 |
|---|---|---|---|
| 1 | 切点漏报 / 误报 | 人工复核后为 0 | 切点前后各一帧并排看 |
| 1 | 节拍与重音 | 重音表与听感一致 | 重音时刻叠加闪白回放 |
| 2 | 身份正确率 | 抽查 100% 是主角 | 每个镜头段首、中、尾叠框看 |
| 3 | 身体重投影误差中位数 | ≤ 5 px（1080p） | 3D 关节投影回原片 |
| 3 | 手 / 脚重投影误差 | ≤ 2.5 / ≤ 7 px | 同上 |
| 3 | 重音停点与 2D 相差 ≤ 1 帧 | ≥ 75% | 打击点表逐个比 |
| 3 | 峰速达到 2D 的 90% | ≥ 80% | 同上 |
| 3 | 锁脚时滑动 | 中位 ≤ 1 cm/s | 接触帧统计 |
| 4 | 母带 | 每帧有效、来源已标注；无抽动帧 | 全片 clay 慢放 + 抽动帧清单 |
| 5 | 取景 | 全身在安全区 ≥ 97% 帧；主角 ≥ 20% 画高 | `report.json` |
| 6 | 内容 | 无黑场、无服装走样、无多余人物 | 每条缩略图条 |
| 7 | 对拍 | 关键动作人工抽查 ≤ ±2 帧 | clay / 成片同帧并排 |
| 7 | 响度 | −12 LUFS ±0.5；真峰值 ≤ −1 dBTP | `ebur128=peak=true` |
| 7 | 规格 | 1080×1920，H.264，`+faststart` | ffprobe |

> 自动姿态 QC 在暗场、高机位、小人物上不可靠（范例横版 31 个镜头里自动判定只有 1 个 PASS，人工看过后全部可用）。自动指标用来排查，最终靠人看。
