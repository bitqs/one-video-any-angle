# 第 1 步 素材与节拍

目标：拿到一条干净、可逐帧分析的原视频，以及与它逐帧对齐的音乐节拍和重音。后面所有机位设计、特效触发和对拍，都以这里的时间轴为准。

## 选片

| 项 | 要求 | 原因 |
|---|---|---|
| 分辨率 | ≥ 1080p，最好 4K | 手指、脚尖的 2D 点在 4K 上才准（手部误差 22 px → 2 px） |
| 主角 | 全身入画的时间越多越好 | 半身 / 特写段落拿不到腿脚，只能推断补全 |
| 镜头 | 切换越少越好，避免叠化 | 叠化帧没有可用的 2D 骨骼 |
| 帧率 | 25 / 30 fps | 全流程只在 30 fps 上验证过 |
| 长度 | ≤ 5 分钟 | 一条动作母带的工作量和显存都按这个量级估 |

## 预处理

- **解码走 GPU**：`ffmpeg -hwaccel cuda … scale_cuda … -pix_fmt bgr24` 管道读帧，约 300 fps；OpenCV 软解 VP9 只有约 20 fps。
- **有效画面**：老片常是 4:3 嵌在 16:9 里（范例 1080p 下有效列 x 251–1669），先记下有效区域。
- **遮挡区**：烧录字幕、台标的位置记下来（范例：1080p 第 1020–1075 行），抠像和参考视频里要挖掉。

## 切点

1. `ffmpeg … -vf scdet=threshold=4` 自动找切点（范例 322 秒检出 67 个）。
2. **必须人工复核**：范例里漏了 4 个、误报了 4 个（舞台灯光突变被当成切点）。
3. 切点之间就是一个「镜头段」：跟踪器在每个切点重置，3D 复原也按镜头段分段跑。

## 音乐节拍与重音

1. **分轨**：demucs（`htdemucs_ft`）拆出鼓、贝斯、人声、其他。
2. **节拍**：librosa 求节拍与速度（范例 112 BPM），存下每拍时间。
3. **重音曲线**：从鼓轨算 kick / snare、从贝斯轨算 bass 的起音强度，重采样到视频帧率（每帧一个值）。
4. **重音表（hitmap）**：挑出最重的几十个时刻并标强度（★ 最强、● 次之）。后面：
   - 机位设计时，招牌动作和最强重音落在「正面」；
   - 特效（闪光、火花、冲击波）挂在这些时刻上；
   - Seedance 提示词里写成「片段第几秒」。
5. **母带**：整首音乐做一次响度母带（范例 −12 LUFS，真峰值 ≤ −1 dBTP），成片音频都从这条切。

## 产物

`cuts.txt` · `beats.npz`（节拍、速度）· `curves.npz`（逐帧 kick / snare / bass）· `hitmap.json` · `remaster.wav`
