# 第 6 步 多角度 AI 视频生成（Seedance 2.5 编辑模式）

目标：把每个 clay 镜头「换皮」成真人质感的画面，动作、机位、时间点逐帧继承。

## 为什么必须用编辑模式

参考模式下模型只是「模仿」参考里的动作，结果「动作完全不一样」，也卡不上拍。编辑模式把 @视频1 当作被编辑的底片：在范例的测试镜头上，手臂 / 腿与泥塑的贴合度从 0.68 / 0.69 升到 0.75 / 0.78，偏移 0 帧，构图与泥塑一致。

## 一次请求的组成

```json
{
  "model": "doubao-seedance-2-5-…",
  "content": [
    {"type": "text", "text": "<编辑模式提示词>"},
    {"type": "video_url", "video_url": {"url": "<clay.mp4 签名URL>"}, "role": "reference_video"},
    {"type": "video_url", "video_url": {"url": "<同秒原片参考 签名URL>"}, "role": "reference_video"}
  ],
  "duration": -1,
  "ratio": "adaptive",
  "resolution": "720p",
  "generate_audio": false,
  "watermark": false
}
```

- `duration: -1` + `ratio: "adaptive"`：时长和画幅跟随 @视频1（竖屏 clay 就出竖屏）。
- 参考视频放私有对象存储，用 24 小时签名 URL；**文件名按内容哈希命名**（曾经同名覆盖，导致 3 个镜头用了别的镜头的参考）。

## 两段参考

| 参考 | 内容 | 作用 |
|---|---|---|
| @视频1 | clay.mp4 | 动作、机位、景别、时间点——逐帧继承 |
| @视频2 | 同一秒的原片（裁到 16:9） | 长相、发型、服装、动作质感 |

**@视频2 被拒时的退路**（被拒不扣费）：露脸原片 → 模糊脸（框必须用修正后的身份放）→ 帽檐黑影。也可以用**人物设定表图片**（正 / 侧 / 背 / 特写）代替原片，图片宽高比要在 0.39–2.5 之间。

## 提示词结构（v4）

完整模板见 [templates/prompt_edit_mode.md](../templates/prompt_edit_mode.md)。要点：

1. **开头**：「编辑 @视频1。@视频1 是唯一的编辑底片……逐帧继承」——不要把 @视频1 叫「参考」，否则会滑向参考模式。
2. **替换句式**：「把 @视频1 里的人换成 @视频2 里的领舞者，动作完全模仿 @视频1」「@视频1 的灰色地面、网格背景和泥塑质感全部换成……」。
3. **服装逐项写清**：身材、帽子、西装、衬衫、领带、臂章在哪只胳膊、手套与否、裤长、袜子、鞋。
4. **光要具体**：光源位置、硬 / 软、影子、体积光；环境要回应动作（烟的漩涡、鞋底扬尘、衣角摆动）。
5. **一致性句**：「光从第一帧到最后一帧一直亮着、始终冷白；黑西装在任何角度都是纯黑」（范例里一个镜头前 2.3 秒整段黑场、一个镜头西装变成米灰色，加上这句重做后解决）。
6. **重音写成片段秒数**：「第 4.2 秒他踢腿时……」，按含余量的 clay 计时；不要写原演出时间（模型看不懂）。
7. **高机位写清看到什么**：「从高处往下看：画面里主要是他脚下的光圈、帽檐和肩膀」，否则模型会把机位拉回平视。
8. **质感句**：真实皮肤和布料纹理、胶片颗粒、180° 快门；高级感：「构图干净克制，黑是真正的纯黑」。

## 分辨率与价格（火山方舟，2026-10）

计费 token ≈（所有参考视频秒数 + 输出秒数）× 宽 × 高 × 24 / 1024，单价 ¥42 / 百万 token（带视频参考）。

| 分辨率 | 两段视频参考时每输出秒 | 10 秒镜头 |
|---|---|---|
| 480p | ≈ ¥1.2 | ≈ ¥12 |
| 720p | ≈ ¥2.7 | ≈ ¥27 |
| 1080p | ≈ ¥6.1 | ≈ ¥61 |

- 先 480p 试 3–5 个镜头定外观，再整片高清每镜头跑一次。
- 被拒（提交时或出片后）都不扣费；同一账号最多 3 个任务并行。

## 批量跑

- 状态文件 + 日志，可断点续跑；
- 第一个镜头单独先发（验证分辨率被接受），其余边渲 clay 边排队，≤ 3 个并行；
- 每条出片后立刻测对拍（见第 7 步）。

## 出片检查（每条都看，自动 QC 不可靠）

缩略图条（每 1–2 秒一帧）看这些：

- 光有没有整段熄灭、冷暖突变；
- 服装颜色、臂章、手套有没有走样；
- 有没有多出来的人；
- 动作有没有明显漏拍。

内容性错误重做（改提示词）；色偏、亮度、对拍交给后期。
