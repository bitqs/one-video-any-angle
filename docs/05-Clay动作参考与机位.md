# 第 5 步 Clay 动作参考与机位

目标：每个镜头一条「穿衣泥塑」视频，动作取自母带，机位按设计走。它只当控制信号，不追求好看——AI 会把它逐帧「换皮」成真人。

## 泥塑人偶

- **身材**：SMPL-X 中性模型 + 男性体型迁移（betas 拟合到同一副骨架，只改形不改关节），按主角定瘦高。
- **服装壳**：顶点按区域沿法线外推并上色——西装（≈2.6 cm）、白衬衫 V 区、领带、**右上臂白臂章**、裤子、白袜、乐福鞋、礼帽；下摆和裤脚用阻尼弹簧做轻微滞后。
- **脸**：拉普拉斯平滑成无五官（参考里不需要脸）。
- **颜色**：整体中灰，主角用偏冷的非肤色标出。**接近白色的裸体人偶会被 Seedance 输入审核拒掉。**
- **环境**：灰地面 + 地面网格，提示词里明确要求「替换掉」。

## 机位

每个镜头一组关键帧，参数：

| 参数 | 含义 |
|---|---|
| `u` | 镜头内的时间位置 0–1 |
| `az` | 方位角（0 = 观众正面，+ = 观众视角右侧） |
| `dist` | 与人的水平距离（米） |
| `h` | 机位高度（米） |
| `f` | 焦距（16:9 下 36 mm 宽画幅的毫米数） |
| `aim` | 注视点高度（米，离地） |
| `lat` | 偏离人的偏航角（构图偏置） |

PCHIP 插值，机位跟随骨盆（平滑 σ 0.3–0.4 秒）。穿越机（FPV）镜头直接用逐帧路径。

**设计原则**

- 一个镜头 = 一个连续机位，不切；时长 4–15 秒（Seedance 参考视频上限 15 秒）。
- 主角在画面里至少占画高 20%。
- 招牌动作要落在它原本设计好的角度（多为正面 / 斜侧）；最强重音那一帧绕到正面。

## 竖屏取景（抖音）

- 安全区：全身（含帽顶、手、脚）在画面上缘 5% 以下、下缘 22% 以上（底部是抖音的文案和按钮）、左右 3%–97%。
- 不靠试渲染：对每个镜头在「距离缩放 0.45–1.35 × 注视点高度 −0.6 – +0.3 米」上网格搜索，直接用网格投影算全身外框，选**最大**且 ≥ 97% 帧在安全区内的组合。
- 竖屏一律 `lat = 0`（横版的偏置构图会把人推出窄画面）。
- 首尾各多渲 0.4 秒（AI 生成会漂移，后期要从余量里对齐）。
- 输出 720×1280 · 24 fps。

## 产物（每镜头一个目录）

- `clay.mp4`：泥塑参考；
- `camera.npz`：逐帧机位（位置、旋转、视角、演出时间、原片帧号、主角投影外框）——后期特效要用同一机位投影；
- `report.json`：主角占画高、出画帧数、警告。
