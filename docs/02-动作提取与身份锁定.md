# 第 2 步 动作提取与身份锁定

目标：主角在每一帧的 2D 骨骼，而且确定是**他**，不是旁边的伴舞。身份错一段，后面整段动作都是别人的。

## 流程

1. **多人 2D 姿态 + 跟踪**：YOLO11x-pose + ByteTrack 跑全片，在每个切点重置跟踪器 → `pose.npz`（所有人、每帧 17 点 + 框 + 轨迹号）。
2. **每个镜头段选主角**：对候选轨迹做 Viterbi，线索包括服装特征（范例：右上臂白色臂章、是否戴红手套）、位置、框大小、轨迹连续性 → `mj.npz`（主角逐帧框和关键点）。
3. **人工身份修正表**：凡是跟踪器会搞错的地方都写进一张逐帧修正表（overrides），不要改代码：
   - 大屏幕上放映的主角影像；
   - 叠在一起或交叉走位的伴舞；
   - 和主角服装很像的人。
4. **全身 2D**：在 4K 原帧上跑 RTMW（133 点：身体 + 脚 + 脸 + 双手），手部再单独二次检测。
5. **可选 · 抠像**：SAM 2.1 用主角框做提示，逐帧出遮罩（范例 9,658 帧里有 8,614 帧拿到了主角遮罩）。后面做「原片参考」挡脸、做特效遮挡都会用到。
6. **头部框**：从修正后的身份和他自己的脸部关键点算头框，专门用来给原片参考挡脸 / 模糊脸。

## 验收

- 随机抽帧把选中的人画框叠回原片看（身份证据图），每个镜头段至少看首、中、尾。
- 身份表改过的帧，2D 全身要补跑一遍。

## 范例里踩过的坑

- **臂章左右写反**：代码按左臂臂章找人，而他戴在右臂 → 约 23 秒（694 帧）的动作跟到了伴舞身上。服装线索（哪一侧、什么颜色）必须对着原片确认一遍。
- **用错身份做挡脸**：参考视频的模糊框若按旧的身份表放，会落在伴舞头上，把主角的脸露出来 → 平台以「可能包含真人」拒绝。挡脸一律用修正后的身份。
