# 第 3 步 3D 动作复原

目标：主角在统一舞台坐标里的 3D 全身动作（SMPL-X：身体、双手手指、头），逐帧准确，重音处的停顿和爆发不能被平滑掉。

## 流程

1. **GVHMR 分段跑**：每个镜头段单独跑 GVHMR（单目视频 → 世界坐标下的 SMPL-X），显存峰值约 5.8 GB。
2. **对齐到同一个舞台坐标**：每段求一个偏航角和水平位移，把所有段放进同一个舞台坐标系；切点处只做位移的渐变过渡，**不做时间模糊**。
3. **逐帧全身拟合**（SMPLify-X 式）：以 GVHMR 为初值，逐帧拟合到 4K 上的 133 点 2D：
   - 双手 45 维完整手势；
   - 重音处放松平滑先验（否则顿点和爆发被抹平）；
   - **不做整体平滑**。
4. **脚接触锁定 + 骨盆下沉**：只在 2D 和 3D 同时判定静止时锁脚（太空步这类滑步不能锁），再修正骨盆高度。

## 实测效果（范例，1080p 重投影）

| 指标 | 只用 GVHMR | 逐帧拟合 v3 | + 脚接触 v4 |
|---|---|---|---|
| 身体重投影误差中位数 px | 11.1 | 4.53 | 4.36 |
| 脚 px | 16.6 | 8.91 | 6.33 |
| 手 px | 22.3 | 2.08 | 1.96 |
| 重音停点与 2D 相差 ≤ 1 帧 | 74% | 72.8% | 78.2% |
| 峰速 ≥ 2D 的 90% | 41% | 71.4% | 81.7% |
| 锁定接触时滑动 cm/s（中位） | — | 4.25 | 0.26 |

> 第一列来自早期版本，打击点集合与后两列不同，只作量级参考。

耗时：拟合每 320 帧约 9–14 秒（单卡）。

## 原片没拍到的段落

主角被挡、出画或切到观众镜头时没有观测。两种补法，都要**标记为推断**（后续文字、说明卡不能当成真实）：

- 短缺口（< 1 秒）：关键姿态插值；
- 长缺口：用同一节目其他场次的录像补，或按前后动作推断。
