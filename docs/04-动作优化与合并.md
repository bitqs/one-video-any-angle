# 第 4 步 动作优化与合并

目标：一条覆盖全片、每帧都有效的**动作母带**。后面所有镜头都从它切片渲染，所以动作问题必须在这里解决，而不是到生成阶段再去碰运气。

## 合并成动作母带

1. 各镜头段的 3D 动作拼成一条连续时间轴，统一舞台坐标；
2. 每帧记录来源：实测 / 推断补全 / 其他场次；
3. 切点处的位移过渡、身份切换帧单独复查（范例修过 2 处肉眼可见的抽动：一处混合帧、一处跟错人后冻结的拟合）；
4. 需要群舞时，伴舞也做成同样格式的队形母带；不要的人（比如躺在地上的）可以整段剔除。

产物：`motion_master.npz`（逐帧 SMPL-X 参数、顶点、关节、有效标记、来源、缺口信息）。

## 力量感验收

动作「对」不等于动作「有力」。每次改动后跑一遍：

- 重音停点：3D 停住的帧与 2D 相差 ≤ 1 帧的比例；
- 峰速：3D 峰值速度达到 2D 的 90% 以上的比例；
- 慢动作对比视频：clay 与原片并排，重音处放慢看。

## 局部修动作（按导演意见）

修动作永远在 **SMPL-X 参数空间**里做，只动相关关节链，其余帧字节不变；修完写成**新文件**，原母带不动。

范例：「0:07 右手下拍要有力，拍到腿上」，原数据峰速只有 4.9 m/s，手停在离大腿 28–39 cm 的地方。

1. **重定时**：取原动作在这段的手掌轨迹（以肩为原点、在躯干坐标系里表示），用加速曲线（s^2.2）重新走一遍：慢起、重落，撞击时刻对准重音（74.03 秒）。
2. **加大幅度**：沿原轨迹方向放大位移（×1.3）——「轨道不变，只加距离和速度」。
3. **IK 跟随**：每帧用 Adam 优化肩、肘、锁骨、腕的旋转（约 400 步），让手掌落到目标点；撞击后保持 0.2 秒，再在 0.3 秒内渐变回原动作。
4. **结果**：峰速 4.9 → 11.6 m/s，撞击落在重音帧。
5. **同步更新顶点和关节**：母带里存的顶点/关节带有舞台摆放（偏航 + 位移），而参数没有 → 用修改前后的关节做一次刚体拟合（Kabsch），把同样的摆放套到新顶点上。

> 坑：渲染器优先读母带里存的顶点。只改参数不改顶点，渲染出来的动作不会变。
